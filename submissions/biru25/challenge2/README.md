# Challenge 2: Static Site Generation -- biru25

A small static blog built with [Eleventy](https://www.11ty.dev), pre-rendered
at build time into plain HTML and CSS, then deployed permanently to Arweave
using the free [`@ardrive/turbo-sdk`](https://www.npmjs.com/package/@ardrive/turbo-sdk).

> Because AR.IO gateways can't run server-side code, SSG is the ideal model
> for content-heavy, rarely-updated sites like blogs and docs.

## Live Deployment

> After running `npm run deploy`, paste the final TX ID here.

- Arweave URL: `https://arweave.net/<TX_ID>/`
- Blog index: `https://arweave.net/<TX_ID>/blog/`
- Example post: `https://arweave.net/<TX_ID>/blog/hello-permaweb/`

## Run Locally

```bash
cd submissions/biru25/challenge2
npm install          # installs Eleventy + turbo-sdk + mime-types
npm start            # http://localhost:8080, with hot reload
```

Open another terminal and edit any `.md`/`.njk` file -- Eleventy rebuilds
and the browser reloads automatically.

To produce a production build (without serving):

```bash
npm run build        # writes ./dist/
```

## Deploy to Arweave

### Prerequisites

- [Node.js 18+](https://nodejs.org)
- An Arweave wallet JWK. In ArConnect: **Settings -> Wallets -> Export
  Key**, save as `key.json` in this folder. (Git-ignored so you don't leak
  it.)
- A small AR balance. The Turbo bundling service gives you free uploads for
  files under 100 KiB -- this whole blog fits well within the free tier.

### Steps

```bash
npm install          # if you haven't already
npm run deploy       # clean + build + upload
```

The script will:

1. Wipe `dist/`, re-run Eleventy to rebuild everything.
2. Walk the `dist/` folder and upload each file to Arweave via Turbo.
3. Build a
   [path manifest](https://docs.arweave.org/developers/arweave-node-server/advanced-topics/path-manifests)
   that maps clean URLs (e.g. `/blog/hello-permaweb/`) to transaction IDs.
4. Upload the manifest itself.
5. Save the final manifest TX ID to `./deployment-id` and print:

   ```
   Done! Deployed to Arweave.
     https://arweave.net/<MANIFEST_TX_ID>/
   ```

Open the URL -- all routes should work thanks to the manifest.

### Optional: ArNS name

Get a human-friendly name like `biru25.ar.io`:

1. Visit [https://arns.app](https://arns.app) and connect the same wallet.
2. Register a name and point it at `<MANIFEST_TX_ID>`.

## Why SSG on Arweave?

| Advantage                   | Detail                                                           |
| --------------------------- | ---------------------------------------------------------------- |
| Zero server runtime         | Every page is pre-rendered HTML, perfectly served by AR.IO       |
| Great SEO                   | Crawlers get fully-formed documents, not empty JS shells         |
| Author in Markdown          | Keep writing posts the easy way                                  |
| Permanent + content-addressed | Once uploaded, the site can never be tampered with             |
| Pay once, host forever      | No renewals, no bandwidth bills                                  |

For highly interactive apps, see Challenge 3 (CSR) and Challenge 4 (Hash
routing) instead.

## Notes

- Upload only content you own or have rights to publish. Arweave storage is
  permanent and public.
- `key.json` is in `.gitignore` -- **never** commit your wallet.
- Total payload after build is a few tens of KiB, comfortably in Turbo's
  free tier.
