What is this site?

A minimal multi-page website demonstrating file-based routing: every page is its own static HTML file linked via anchor tags. No JavaScript router, no build tool, no server-side code. Perfect for Arweave's permanent, decentralized gateways.

  • Pure HTML + CSS, zero dependencies
  • Fully static -- works on any AR.IO gateway
  • Relative links so it also works under the Arweave hash path
  • Responsive dark theme
